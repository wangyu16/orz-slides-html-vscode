Code Blocks

// Fibonacci — recursive memoised
function fib(n, memo = {}) {
    if (n <= 1) return n;
    if (memo[n]) return memo[n];
    return memo[n] = fib(n-1, memo)
                   + fib(n-2, memo);
}
console.log(fib(40)); // 102334155
# List comprehension + generator
squares = [x**2 for x in range(10)]
even_sq  = (x**2 for x in range(10)
            if x % 2 == 0)

Callout Boxes

Info: Use this for supplementary information, tips, or notes that add context without interrupting the main flow.

Warning: Use this for caveats, potential pitfalls, or things the audience should pay attention to.

Success: Confirm a completed step, a correct answer, or a positive outcome.

Danger: Reserved for errors, critical warnings, or irreversible actions.

Four semantic callout types. Use consistently — don't swap their semantic meanings.

Row Stacking

Rule: Once a parent row or col is split into child containers, do not mix bare content with those child containers. Use two or more child rows or cols to occupy that parent, then place content inside each child. This keeps the rendering logic explicit and easier to maintain.

Left detail

This row contains only child cols. Put the explanation, bullets, image, or table inside those child containers.

Right detail

Avoid adding a parent-level heading or paragraph beside the child cols. Keep the parent dedicated to structure.

Rows stack vertically. Reinforce the authoring rule: once a parent is split into child containers, keep visible content inside those children rather than beside them.

Center Container

The Central Message

Use [[center[width] content]] when you want a single focused element centered both horizontally and vertically.

Width accepts 0.65, 65%, or 2/3. A center container cannot have siblings.

Float Container

Main body content. The text here fills the regular flow of the slide. Float containers sit on top of everything else.

Key points about this topic:

  • Float is positioned from the top-left corner of the slide
  • Coordinates and width use %, fractions like 1/2, or decimals like 0.5
  • Multiple floats can overlap each other
